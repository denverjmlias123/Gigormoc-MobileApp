# SQL bundles (reference only)

These files are concatenations of `supabase/migrations/`, generated by `scripts/build_full_migration.js`
(`LOOP_RPC_INSTALL.sql` is a hand-made subset).

**Do not paste them into the Supabase SQL editor.** That desyncs the migration history (AGENTS.md rule 7).
Apply schema changes with `npx supabase db push`. The source of truth is always `supabase/migrations/`.
